## 📂 Projects

#### 🚘 [EV Telematics & Odometry ECU](https://github.com/abdullahshabbir2/autosar-ev-telematics)

Rewrite of a shipped EV telematics ECU that lost odometer data in the field, in an **AUTOSAR Classic-style** five-layer architecture on ESP32: CAN, RS485, GNSS, crash-safe NvM/Fee persistence and ISO 14229 diagnostic events. **330+ host unit tests**, 129 traced requirements and six CI gates; writing the tests found four defects in already-reviewed code.

`Embedded C` `ESP32` `FreeRTOS` `CAN` `RS485/Modbus` `ISO 14229 UDS` `Unit Testing` `GitHub Actions`

#### 🌬️ [Connected Air Purifier](https://github.com/abdullahshabbir2/AirPurifier)

ESP-IDF firmware that computes the US EPA AQI on-device (2024 PM2.5 breakpoints), drives the fan closed-loop with hysteresis, publishes telemetry over REST and a BLE GATT service, and provisions Wi-Fi over BLE. **120 host unit tests** run in CI.

`ESP32` `ESP-IDF` `FreeRTOS` `BLE` `REST API` `Unit Testing` `GitHub Actions`

#### 🚰 [Home Assistant Cistern Integration](https://github.com/abdullahshabbir2/home-assistant-cistern-integration)

Custom Home Assistant integration with Zeroconf discovery and coordinator polling, plus ESP32 REST firmware for cistern monitoring and irrigation control.

`Python` `Home Assistant` `ESP32` `REST API`

#### 📶 [Quectel M95 GSM MQTT](https://github.com/abdullahshabbir2/quectelm95_gsm_mqtt)

MQTT over a Quectel M95 GSM modem with AT-command response validation and separated configuration, used for EV telemetry uplink.

`C++` `GSM` `AT Commands` `MQTT`

#### 🌱 [Smart IoT Greenhouse](https://github.com/abdullahshabbir2/Smart_IoT_GreenHouse)

Dual-node ESP32 greenhouse controller with local dashboards, REST APIs, mDNS, NVS persistence, watchdog recovery, fan hysteresis and pump lockouts.

`ESP32` `C++` `REST API` `mDNS` `NVS`
